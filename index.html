Transaction Monitoring System

GitHub

A Spring Boot service that flags suspicious deposits with pluggable rules, queues alerts for an analyst and records every decision. A structuring rule and a profile-deviation rule ship with it, and the analyst gets a drafted case summary built from mock sanctions and public-record data. A person makes the final call.

Java 17, Spring Boot, PostgreSQL, JUnit, Mockito

Design Review Tool

GitHub

Upload a design drawing, click to pin a comment where the problem is, reply in the thread and mark it resolved. Pin positions are stored as fractions of the image, so they stay on the right spot at any zoom or screen size.

React, TypeScript, Vite, FastAPI, SQLite, pytest

MUN Course Planner

GitHub

Builds semester-by-semester plans for MUN Computer Science students from the 2026-27 calendar. It enforces prerequisites, co-requisites, offered terms and degree requirements, shows progress toward the major, and lets students rate courses. Averages stay hidden until three people have rated, so one opinion can't decide anything.

Python, FastAPI, SQLite, React, TypeScript, Vite
